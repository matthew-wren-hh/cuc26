# Lesson 07 - Macros and Reuse

## Focus
Reduce duplication with shared formats and macros.

## Key concepts
- Velocity macros and includes
- Shared formats for cards and buttons
- Pattern libraries in Cascade

## Hands-on
- Create a macro for the profile card
- Reuse the macro on the home page and content page

## Outcome
Participants can reduce repeated markup with reusable tools.
