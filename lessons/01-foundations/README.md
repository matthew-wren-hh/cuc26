# Lesson 01 - Foundations

## Focus
Core Cascade concepts, UI tour, and where content lives.

## Key concepts
- Sites, folders, pages, blocks, and formats
- Where XML lives and how it is generated
- Global variables and basic Velocity context

## Hands-on
- Create a site and folders that match the scaffold in `site/`
- Review how a page asset stores XML for a data definition

## Outcome
Participants can describe how Cascade stores and renders content.
