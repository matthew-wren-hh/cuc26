# Cascade Essentials - Workshop Overview

## Purpose
Introduce Cascade CMS basics, then move into developer workflows that transform structured content into HTML.

## Audience
Beginner developers and advanced content editors who support Cascade sites.

## Flow
1. Foundations and terminology
2. Assets, pages, and blocks
3. Data definitions and structured content
4. Velocity basics
5. Mapping data definitions to HTML
6. Index blocks and Query API
7. Macros and reusable formats
8. Wrap-up and next steps

## Outcomes
- A working static university site ready for Cascade mapping
- Clear exercises that pair data definitions with Velocity formats
- A shared vocabulary for troubleshooting and content workflows
