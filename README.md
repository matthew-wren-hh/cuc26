# Cascade Essentials Workshop

Static site scaffold and lesson flow for the Cascade Essentials workshop.

## Structure
- `site/` - HTML, CSS, and JS for the demo university site
- `lessons/` - lesson flow and exercises
- `data-definitions/` - placeholders for data definition files
- `velocity/` - placeholders for Velocity formats and macros
- `blocks/` - placeholder notes for block examples

## Pages
- `site/index.html` - home page
- `site/content.html` - standard content page
- `site/news/index.html` - news listing
- `site/news/detail.html` - news detail

## Run
Open the HTML files directly in a browser.
